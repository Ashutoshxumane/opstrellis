You need a paid commercial license from the author for any commercial purpose, for example:

- Using OpsTrellis at or for a company, including dictating for paid work.
- Selling, reselling or bundling OpsTrellis, or a modified version of it, in a product or service.
- Running the OpsTrellis Cloud server (`server/`) for customers or as a paid or hosted service.
- Using any part of the source code in a commercial product.

## What is free

- Personal use on your own computers.
- Hobby projects, study, research and experiments that aren't for commercial gain.
- Use by charities, schools, public research and government bodies, as defined in the
  [license](LICENSE).
- Reading, modifying and sharing the code for noncommercial purposes, keeping the license and
  the "Required Notice" line.

If you're unsure whether your use is commercial, ask before using it.

## Getting a commercial license

Open an issue titled **"Commercial license"** at
<https://github.com/mtr1920/opstrellis/issues/new> or contact the author through
<https://github.com/mtr1920>, and describe how you plan to use OpsTrellis (company, number of users,
whether you'd distribute or host it). You'll get the terms and pricing.
